<h1>UPI-Tracker</h1>
This is a simple utility project (expense tracker) that aims to do little more than just expense tracking.<br/>
Offline storage and not reliant on internet/bluetooth...dependent on cellular network for receiving UPI-SMS message.

<br/><br/>

Features:<br/>
1) Track income/expense
2) Minimize user effort for recording transactions (parse SMS to extract UPI payments)
3) Track IOU with friends (exactly like Splitwise)
4) Balance tracking for pools of money(cash, savings, FD, investments)
5) Import transactions from bank statement(HDFC, .xls format)

<br/>

Future implementation plans (subject to my interest):
1. Statistics (category wise expenditure)
2. Send/receive transactions to friends for record keeping (coded message via SMS)
3. Better UI ;)
